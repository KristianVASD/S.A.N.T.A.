-e # SANTA Progress Agent - Resource Direction Guide

## Overview
The Progress Agent directs SANTA's research resources toward regions and sectors that need deepening based on data coverage, user demand, and trust assessment gaps.

## Core Responsibilities
- Monitor coverage levels across regions
- Track sector-specific trust dimensions
- Prioritize resource allocation
- Document progress and gaps

## Trust Dimensions
- Professional Identity (High)
- Professional Quality (High)
- Safety (Medium)
- Community (Medium)
- Customer Experience (Medium-High)

## Coverage Levels
- Level 0: New Location - No verified data
- Level 1: Basic - Company exists verified
- Level 2: Standard - Certifications verified
- Level 3: Deep - Reviews, negative signals
